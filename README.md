# College Events App

A team project from college: I built this React frontend for college events. You can browse events, search them by title, type, location and date, create new ones and edit them. Users can sign up, log in, register for events and see everything on their profile page.

Made as a college project in 2024.

## Features
- Event list with search and filters (title, type, location, date)
- Create and edit events in a modal form
- Sign up / log in, with the session kept in localStorage
- Event registration and a personal profile page

Events, users and registrations came from a REST API built by my teammate and hosted on Azure. That server is no longer running, so the app needs a backend to show data.

## Built with
React · JavaScript · REST API (Azure)

## Run it locally
```bash
npm install
npm start
```
